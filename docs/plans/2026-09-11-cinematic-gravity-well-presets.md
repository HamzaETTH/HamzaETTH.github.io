# Cinematic Gravity-Well Presets Implementation Record

**Goal:** Keep all existing 96 presets, add 24 distinctive spectacle presets, reserve their full particle envelope, prevent black-core trapping, and bound catastrophic line work without letting the rendering shortcut alter particle physics.

- **Impossible Machines:** Mobius Engine, Gyroscope Temple, Parallax Gate, Gravity Prism, Kinetic Mobile, Wave Interferometer.
- **Living Cosmos:** Dragonfly Rift, Jellyfish Gate, Phoenix Wake, World Tree, Skull Nebula, Leviathan Jaw.

- **Chaotic Arenas:** Thunderhead, Gravity Harp, Volcano Rift, Solar Sail, Orbital Fountain, Quasar Lighthouse.

The final catalogue contains 120 presets in 15 families. Every addition uses 10–14 wells, a recommended 60% all-wells force, capped acceleration, nonzero family spin, and Orbit Assist-compatible motion. Seven full-canvas compositions use wide deterministic spread placement: Parallax Gate, Wave Interferometer, Phoenix Wake, Leviathan Jaw, Thunderhead, Solar Sail, and Quasar Lighthouse.

## Shared safeguards

1. Layout solving reserves artwork separately from the particle envelope: `2.805r + 3px` on desktop and the complete `2r + 3px` mobile influence range. Orbit Assist ratios remain an independent contract.
2. The black-hole profile uses a `1.8r` safe shell and stronger core repulsion. While Orbit Assist is active, the strongest outward black-halo escape survives controller blending, so a nearby white well cannot press particles into another black core.
3. When Adaptive Line Detail is enabled, predicted grid pair work or catastrophic cell occupancy enters a point-only frame immediately. All particles and pair forces remain active; only connection generation is skipped. Twelve safely sparse frames release the guard.
